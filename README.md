# Консольный калькулятор 

---

* **Основные операции:**
  * `+` — сложение
  * `-` — вычитание
  * `*` — умножение
  * `/` — деление
* **Защита от деления на ноль:** при попытке разделить на 0 выводится ошибка, а текущий результат сохраняется без изменений.
* **Управляющие команды (без учета регистра):**
  * `c` / `C` — сброс текущих вычислений и обнуление результата.
  * `s` / `S` — безопасный выход из программы.
* **Валидация ввода:** обработка нечисловых значений и неподдерживаемых операторов.
